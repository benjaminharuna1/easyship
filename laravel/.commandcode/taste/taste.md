# Taste

## Communication & workflow
- Explicitly welcomes and requests recommendations for improvements alongside the core task, not just the literal change ("also recommend improvements if any"). Confidence: 0.7
- Multi-file changes that touch routing/design decisions benefit from a plan-first pass with clarifying questions before implementation (engaged with plan mode and answered design questions). Confidence: 0.55
- For bug fixes/code changes, prefers the agent to just implement the fix without extensive agent-side testing or demoing — the user will verify, test, and check the changes on their own ("i will check for changes and test on my own. Just build the code thanks."). Confidence: 0.6
